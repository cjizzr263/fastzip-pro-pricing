## 免费版和 Pro 差在哪

这款软件分了免费版和 Pro 两个版本，免费版能做的事已经覆盖了大多数人的需求：打开压缩包，解出来。中文文件名乱码、RAR 双击打不开、想知道里面有什么必须先解压，这几个 Mac 自带归档工具的老毛病，免费版都能解决。

判断标准其实很简单。你的动作主要是“解”，免费版够了。你的动作里有一半是“压”并且要发给别人，Pro 才划算。
